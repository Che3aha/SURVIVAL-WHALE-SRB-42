# The Hitchhiker’s Survival Guide Through Serbia’s Parks

<img width="1052" height="650" alt="image" src="https://github.com/user-attachments/assets/cfcc7dbe-c84b-4b2d-bb29-c6ea3a567230" />

A futuristic, multilingual and satirical landing page for a questionably essential Serbia survival kit.

The project presents four survival items for visitors attempting to navigate Serbian national parks, traffic, borders, queues, signs and conversations without becoming unnecessarily reasonable.

## The survival kit

- **Hold the Game, Do Not Panic — Game** — a downloadable satirical field-guide game.
- **Babel Fish Translator** — a translation application supporting more than 130 languages online.
- **Džu Džanta 200 Glasses** — five danger-sensitive visor designs available as part of the complete kit.
- **Nacionalni Park Srbija** — analogue entertainment for queues, delays and traffic that has become a permanent address.

## Publish with GitHub Pages

1. Upload `index.html`, `README.md` and the complete `assets` folder to the root of the repository.
2. Open the repository’s **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and the `/root` folder.
6. Click **Save**.

GitHub will provide the public website address after deployment finishes.
